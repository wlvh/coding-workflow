# 独立影响核实

与 [核实流程](finding_verification.md) 一起使用。
你使用来自 OpenAI 以外另一家 LLM 公司的 LLM，独立于作者、正式 PR 审查者和 Codex 事实
核实者，对同一准确候选和整批阻断问题调查影响。初报完成前不读取 Codex 的核实结论。

沿真实输入、状态、调用方与用户入口，检查问题是否只是一个实例，是否还有同类入口、
相邻场景、持久化数据或跨模块组合受影响。核对实际触发前提与后果，不依据文件相邻、
import 关系或模型猜测扩大修复范围；发现事实核实前提有误时给出反证。

比较修复方案：怎样保留核心目标并减少必要改动，能否删除问题机制或复用已有能力，哪些
兼容、恢复或失败语义需要保留。指出必要的测试、用户说明和接口约定更新；复用一条组合
场景能证明多项问题时，说明它覆盖的范围。

按共享流程与 Codex 最多交流三轮。每轮实际读取其报告或综合分析，对重要分歧明确回应，
保留自己维持或改变结论的依据，以及尚缺证据。风格偏好与未来功能单列为非阻断建议。

你保持只读。成立问题由 Codex 事实核实会话修复。
